# SHPH Evidence Directory

This directory contains reproducibility artifacts, not source-of-truth code.

- `GATE_EVIDENCE.md` is generated by `scripts/capture_evidence.sh` and records
  the exact tree, toolchain, platform, validation gates, and demo result.
- `CARGO_AUDIT.txt` is the latest captured `cargo audit --no-fetch` output.
- `WINDOWS_NATIVE_VALIDATION_2026-08-09_POST_LOADER.md` is the latest native
  Windows workspace, Windows-only test, benchmark, and post-loader Wintun
  host-gate record.
- Dated benchmark and public validation reports elsewhere under `docs/` are
  retained as historical or phase-specific evidence and identify their own
  platform and scope. Internal assessment material is maintained outside the
  publishable evidence bundle. None of these records is an independent audit.

Regenerate the current gate record from the repository root:

```bash
./scripts/capture_evidence.sh
```

The script refuses dirty trees by default. Use `--allow-dirty` only for
intermediate engineering evidence, and keep the resulting `tree=dirty` label.

## Publication handling

Before publishing evidence to GitHub, review every file for private keys,
keystore material, peer addresses, hostnames, usernames, absolute paths, and
unredacted packet or command logs. The two-host validator stores its private
state outside the repository by default; publish only its generated,
sanitized Markdown reports and explicitly reviewed supporting data.
